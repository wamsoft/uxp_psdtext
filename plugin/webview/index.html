これは何

アクティブドキュメントのテキストレイヤの本文を、単体でもまとめてでも書き換えるパネル。 Photoshop 側の変更 (レイヤの追加・削除・編集・ドキュメント切替) は自動で追従する。

レイヤ一覧

  • 既定ではテキストレイヤだけが並ぶ (「テキスト」フィルタを外すと全レイヤ)
  • クリックで選択 / Ctrl+クリックで追加・解除 / Shift+クリックで範囲選択
  • 行末の ✎、ダブルクリック、F2 のどれでも単体編集 (名前・本文・書式をまとめて 1 画面で。適用は履歴 1 段)
  • 検索欄はレイヤのパスと本文の部分一致
  • テキスト全選択: 表示中のテキストレイヤを全部選択

まとめて編集…

対象 (全テキストレイヤ / 選択中) を表にして、レイヤ名・本文・基準書式 (フォント / サイズ / 色 / 揃え) を列ごとに編集する。変わったセルに色が付き、 適用で変わった行だけが Photoshop に反映される。適用は履歴 1 段なので Ctrl+Z 1 回で全部戻る。書式列を変えても本文途中の部分書式は保たれるが、 本文を書き換えた行は途中の書式が外れる (件数を報告)。 規則ベースの一括リネームは姉妹ツールの PSD Power Rename へ。

見出しのチェック (またはプリセットボタン) で、コピー / 貼り付けに 効かせる列を選ぶ。表をコピーは対象列だけを TSV で書き出す。 Excel で編集したら「TSV を貼り付け」で先頭行から流し込むか、 セルに Ctrl+V でそのセルを起点に右の対象列 → 下の行へ流し込む。 編集そのものはチェックに関係なくいつでもできる。

部分書式

単体編集の本文は見たまま編集 (エディタエンジンは Quill)。 太字・色・フォント・サイズ・行ごとの揃えがそのまま表示され、 範囲選択 (またはカーソル位置から) B / I / U / サイズ / 色 / 揃えボタンで 直接変わる。エディタ内は Ctrl+Z / Ctrl+Y で取り消し・やり直しできる。 「基準へ」で選択範囲の書式を消せる。表示上の文字サイズは 基準が約 14px になるよう縮めてある (実サイズは pt の値のとおり)。

右上の「タグ」ボタンでタグ編集モードに切り替えられる (一括置換など、テキストとして書式をいじりたいとき用)。

タグモードの文法: [b]太字[/b] [i]斜体[/i] [u]下線[/u] [s]取り消し線[/s] [size=96]大きく[/size] [color=#FF0000]赤[/color] [font=...] [leading=14] (行間。auto も可) [tracking=-50] (字送り) [reset]。 閉じタグは「基準へ戻す」の意味。 文字としての [ は [[ と書く。

その他

  • フォント欄の候補はお気に入り + このドキュメントで使用中のものだけ。 全フォントからの検索と登録は ★ ボタン (編集画面の基準欄の隣、シートのフォント ▾ →「お気に入りを管理…」) から
  • セル内の改行はそのままレイヤの改行になる
  • 再読込: レイヤ一覧を取り直す (通常は自動追従するので不要)
  • Ctrl+D: 自己診断行の表示 (不具合調査用)

What is this

Edits the contents of the text layers of the active document — one at a time or in bulk. Changes on the Photoshop side (add / delete / edit / document switch) are tracked automatically.

Layer list

  • By default only text layers are listed (uncheck "Text" to see everything)
  • Click to select / Ctrl+click to add or remove / Shift+click for a range
  • The ✎ at the end of a row, a double-click, or F2 all open the single-layer editor (name, contents and formatting in one view; one history step)
  • The search box matches layer paths and text contents
  • Select all text: selects every listed text layer

Edit all…

Puts the targets (every text layer, or the selection) in a table with columns for the layer name, contents and base style (font / size / color / alignment). Changed cells are highlighted; Apply sends only the changed rows as a single history step, so one Ctrl+Z undoes everything. Style-column edits keep the formatting inside the body; rewriting the body drops it (reported per row). For rule-based bulk renaming see the sister tool PSD Power Rename.

The header checkboxes (or the preset buttons) choose which columns copy & paste touch. Copy table writes the target columns as TSV. After editing in Excel, use Paste TSV to fill from the first row, or Ctrl+V in a cell to flow right through the target columns and down the rows from that cell. Editing itself always works, regardless of the checkboxes.

Per-range formatting

The single-layer editor is WYSIWYG (powered by Quill). Bold, colors, fonts, sizes and per-line alignment render as they are; select a range (or just place the cursor) and use the B / I / U / size / color / alignment buttons. Ctrl+Z / Ctrl+Y undo and redo inside the editor. "To base" clears the selection's formatting. Displayed sizes are scaled so the base is about 14px (the real pt values are unchanged).

The "Tags" button switches to tag-editing mode, for when you want to manipulate formatting as text (bulk replacements etc.).

Tag-mode syntax: [b]bold[/b] [i]italic[/i] [u]underline[/u] [s]strikethrough[/s] [size=96]big[/size] [color=#FF0000]red[/color] [font=...] [leading=14] (line spacing, auto allowed) [tracking=-50] [reset]. A closing tag means "back to the base style"; a literal [ is written [[.

Misc

  • Font fields list only favorites + fonts used in this document; search and register from all fonts via the ★ button (next to the base row in the editor, or the font cell ▾ → "Manage favorites…")
  • Line breaks inside a cell become line breaks in the layer
  • Reload: fetch the layer list again (normally unnecessary — it tracks automatically)
  • Ctrl+D: toggle the self-diagnosis line (for troubleshooting)

Edit text layers

Help

これは何

アクティブドキュメントのテキストレイヤの本文を、単体でもまとめてでも書き換えるパネル。 Photoshop 側の変更 (レイヤの追加・削除・編集・ドキュメント切替) は自動で追従する。

レイヤ一覧

  • 既定ではテキストレイヤだけが並ぶ (「テキスト」フィルタを外すと全レイヤ)
  • クリックで選択 / Ctrl+クリックで追加・解除 / Shift+クリックで範囲選択
  • テキストレイヤをダブルクリック または F2 で単体編集
  • 検索欄はレイヤのパスと本文の部分一致
  • テキスト全選択: 表示中のテキストレイヤを全部選択

まとめて編集…

対象 (全テキストレイヤ / 選択中) を表にして、レイヤ名と本文を編集する。 変わった行は色が付き、適用で変わった行だけが Photoshop に反映される。 適用は履歴 1 段なので Ctrl+Z 1 回で全部戻る。名前を空にした行は名前を変えない。 規則ベースの一括リネーム (連番・検索置換) は姉妹ツールの PSD Power Rename へ。

TSV でコピーで「レイヤ名 (タブ) 本文」をクリップボードへ書き出せる。 Excel やスプレッドシートで編集して、表の貼り付け開始行のセルに貼り付けると 下方向にまとめて流し込まれる。1 列だけ貼ると貼った列 (名前 or 本文) に、 2 列以上を貼ると先頭列が名前・最後の列が本文になる。

その他

  • セル内の改行はそのままレイヤの改行になる
  • 再読込: レイヤ一覧を取り直す (通常は自動追従するので不要)
  • Ctrl+D: 自己診断行の表示 (不具合調査用)

What is this

Edits the contents of the text layers of the active document — one at a time or in bulk. Changes on the Photoshop side (add / delete / edit / document switch) are tracked automatically.

Layer list

  • By default only text layers are listed (uncheck "Text" to see everything)
  • Click to select / Ctrl+click to add or remove / Shift+click for a range
  • Double-click a text layer (or press F2) to edit it on its own
  • The search box matches layer paths and text contents
  • Select all text: selects every listed text layer

Edit all…

Puts the targets (every text layer, or the selection) in a table where both the layer names and the contents can be edited. Changed rows are highlighted; Apply sends only the changed rows to Photoshop as a single history step, so one Ctrl+Z undoes everything. Rows with an emptied name keep their name. For rule-based bulk renaming (numbering, find & replace) see the sister tool PSD Power Rename.

Copy as TSV puts "layer name (tab) contents" on the clipboard. Edit in Excel or a spreadsheet and paste back into the cell where the fill should start — the rows flow downwards. A single pasted column goes into the column you pasted into (name or contents); with two or more columns the first becomes the name and the last the contents.

Misc

  • Line breaks inside a cell become line breaks in the layer
  • Reload: fetch the layer list again (normally unnecessary — it tracks automatically)
  • Ctrl+D: toggle the self-diagnosis line (for troubleshooting)
